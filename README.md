# HR_analytic-
HR Analytics Project

A simple data analysis of employee data using Python.

About

This project looks at 1,500 employees to understand who stays, who leaves, and how pay and satisfaction look across the company.

Tools
Python
pandas
matplotlib
seaborn
Jupyter Notebook
Data

The data has 15 columns, such as department, job level, salary, bonus, performance rating, satisfaction score, and status (Active, Resigned, or Terminated).

What I did
Cleaned the data
Changed Hire_Date to a date format
Checked for missing values and duplicates
Turned performance rating into a number
Added a Left column (1 = left, 0 = still active)
Made charts
Employee status
Employees by department
Attrition rate by department
Average salary by job level
Satisfaction score by status
